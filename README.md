## Descripción del proyecto
Este proyecto realiza un análisis simple de ventas utilizando Python.

Se trabajó utilizando herramientas de organización y control de versiones como Jira y GitHub, aplicando un flujo de trabajo basado en metodologías ágiles.

## Objetivos
- Analizar datos de ventas.
- Calcular ventas totales.
- Identificar el producto más vendido.
- Generar un archivo de resumen con los resultados.

## Tecnologías utilizadas
- Python
- Git
- GitHub
- Jira

## Estructura del proyecto

```text
datos/ -> archivo CSV de ventas
scripts/ -> script principal de análisis
resultados/ -> resultados generados
```

## Archivo principal
El script principal es:

```text
scripts/analisis_ventas.py
```

## Dataset utilizado
El archivo utilizado para el análisis es:

```text
datos/ventas.csv
```

## Resultados obtenidos
El programa genera:
- total de ventas,
- ventas por producto,
- producto más vendido,
- archivo resumen.txt.
